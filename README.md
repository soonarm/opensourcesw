# 오늘 뭐 먹지? 🍽️

룰렛을 돌려 오늘의 점심 메뉴를 추천받는 단일 페이지 웹 앱입니다. 한식, 중식, 일식, 양식 카테고리 필터를 제공하며, 별도 백엔드나 데이터베이스 없이 브라우저에서 바로 실행됩니다.

## 프로젝트 구성

- `index.html`: HTML, CSS, JavaScript가 포함된 실행 파일
- `requirements.txt`: 외부 Python 패키지 없음
- `.gitignore`: 인증정보, 개인정보, 캐시·로그·생성 파일 등의 업로드 방지 규칙

## 설치 방법

Python 3가 설치되어 있다면 별도 패키지 설치가 필요하지 않습니다.

```bash
python --version
```

`requirements.txt`는 프로젝트 관리 및 배포 일관성을 위해 포함되어 있으며, 설치할 패키지는 없습니다.

## 모델 준비 방법

이 프로젝트는 AI 모델, 대용량 모델 파일 또는 외부 API를 사용하지 않습니다. 따라서 모델 다운로드나 별도 모델 준비 과정이 필요하지 않습니다.

## 실행 방법

### 방법 1: 브라우저에서 직접 실행

`index.html`을 웹 브라우저로 열면 바로 사용할 수 있습니다.

### 방법 2: 로컬 정적 서버 실행

프로젝트 폴더에서 다음 명령을 실행합니다.

```bash
python -m http.server 8000
```

그 후 브라우저에서 `http://localhost:8000/index.html`을 엽니다.

## 사용 방법

1. 전체 또는 원하는 음식 카테고리를 선택합니다.
2. `오늘 뭐 먹지?` 버튼을 누릅니다.
3. 룰렛이 멈추면 화살표가 가리키는 메뉴가 결과로 표시됩니다.

## 배포 참고

GitHub 저장소에 `upload` 폴더 안의 파일을 올리거나, 폴더 내용을 저장소 루트로 이동해 GitHub Pages로 배포할 수 있습니다. 서버나 환경변수 설정은 필요하지 않습니다.
